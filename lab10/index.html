Design Reflection

I chose Lab 9's world GDP choropleth and cartogram to extend with browser-based voice control. Users can say “Show Asia,” “Highlight Japan,” or “Reset” to filter the top-50 economies, select a country, and restore the overview, supporting a rapid country lookup with user's hands free. Voice is appropriate for this task because each existing command has a corresponding short phrase, and does not require precise pointing on a dense world map. A key limitation is that the system only recognizes a predefined set of commands, so repeated, modified, or unsupported utterances may fail to trigger the intended action. In testing, the voice command can be misheard because of accents, background noise, or microphone quality, since the speech recognition relies on an external browser service.
